# ASSET PRODUCTION PLAN
# Aether Harvester Simulator

## Overview
This document outlines the asset production plan for *Aether Harvester Simulator*, including tool models, creature models, island biomes, props, UI mockups, and particle effects. Each asset is categorized by priority (P0: MVP, P1: Post-Launch) and includes AI generation prompts, Roblox import settings, and detailed descriptions.

---

## 1. Tool Models (4 Tiers)

### **Basic Net** (P0)
- **Description**: A simple, lightweight net with a woven aether-infused design. Glows faintly when harvesting.
- **AI Generation Prompt**: "A 3D model of a Basic Net for a sky-based harvesting game. The net is lightweight, woven from glowing aether threads, with a simple handle. The material should look semi-transparent with a subtle blue-purple glow. The net should have a mesh type of 'TriangularMesh' and a material of 'Neon' for the glowing effect."
- **Roblox Import Settings**:

## 5. UI Mockups

### **HUD** (P0)
- **Description**: Clean, minimalist HUD with health, energy, level, XP bar, quick-bar, and minimap.
- **Layout**: Top-left corner for health/energy, top-right for level/XP, bottom for quick-bar, center for minimap.
- **Colors**: Soft blue-purple gradient for background, white for text.
- **Fonts**: Roblox default font with slight customization for readability.
- **Iconography**: Simple, clean icons for tools, health, and energy.


### **Inventory** (P0)
- **Description**: Grid-based inventory with drag-and-drop functionality.
- **Layout**: 3x3 grid with quick-bar above.
- **Colors**: Dark background with glowing item highlights.
